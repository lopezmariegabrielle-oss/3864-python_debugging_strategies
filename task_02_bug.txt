======================================================================
RAPPORT DE DÉBOGAGE : Tâche 2 - Débogage interactif avec 'pdb'
======================================================================

1. Le problème constaté
-------------------------------------
Le programme devait calculer la moyenne de scores ajustés après l'ajout 
d'un bonus. Pour des scores de [40, 60, 80] et un bonus de 10, la moyenne 
attendue était de 70.0. 
Pourtant, le script initial affichait : "Adjusted average: 60.0".

2. L'utilisation de pdb
--------------------------------------------------
J'ai inséré un point d’arrêt dans la fonction de calcul :
-> breakpoint()

Lors de l'arrêt du programme, j'ai utilisé les commandes :
• n (next)  : Pour avancer d'une ligne.
• p (print) : Pour afficher les variables (ex: p raw, p adjusted).

L'inspection a révélé que la variable 'adjusted' calculait bien le score 
avec le bonus (50 pour 40). Cependant, la ligne suivante n'utilisait 
pas la bonne valeur pour le cumul.

3. La solution
-----------------------------------
Le bug venait de la ligne d'accumulation qui ajoutait le score initial 
au lieu du score ajusté :
-> Code erroné : raw_sum += raw

J'ai corrigé la logique en utilisant la variable contenant le bonus :
-> Code corrigé : raw_sum += adjusted

Après suppression du point d’arrêt, le programme affiche le résultat 
correct : "Adjusted average: 70.0".
